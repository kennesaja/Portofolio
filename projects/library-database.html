PROJECT SCOPE

From a service process
to structured records.

The team's process worksheet describes five library activities: registration, borrowing, returns, fine payment, and membership closure. It connects the people involved, required data, procedures, input forms, and intended outputs for each activity.

The coursework develops a library data model and explores table creation, data changes, filtering, joins, aggregate functions, subqueries, and views. Reports document SQL exercises in Oracle APEX and CockroachDB, alongside separate Apache Cassandra setup and CQL exercises.

Database design and query coursework. The project materials document the model and exercises; they do not establish a deployed library application.

02Calculate and sort a new columnIndividual submission · Oracle APEX

This exercise adds five to each publication year and sorts the results. Perkiraan_Revisi is a calculated sample value, not an actual book revision schedule.

SELECT Judul_Buku, Tahun_Terbit,
       Tahun_Terbit + 5 AS Perkiraan_Revisi
FROM Buku
ORDER BY Tahun_Terbit, Perkiraan_Revisi DESC;

04Find books with a borrowing recordGroup coursework · CockroachDB

An EXISTS subquery checks whether each book has a matching record in Peminjaman.

SELECT b.ID_Buku, b.Judul_Buku
FROM Buku AS b
WHERE EXISTS (
    SELECT 1
    FROM Peminjaman AS p
    WHERE p.ID_Buku = b.ID_Buku
);
